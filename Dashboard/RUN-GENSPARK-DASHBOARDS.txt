  Ye file padho – Students CRUD nahi

Jo ab 127.0.0.1:5000 pe dikh raha hai (Students CRUD) wo is project ka NAHI.
GenSpark ke Admin/Vendor dashboards chalane ke liye:

STEP 1: Jo bhi Flask ab chal raha hai use BAND karo
   - VS Code / terminal me jahan "Running on http://127.0.0.1:5000" dikh raha hai
   - wahan jao aur Ctrl+C dabao (server band hoga)

STEP 2: GenSpark run karo – sirf isi folder se
   - Is "vendor dashboard" folder me terminal kholo
   - Command chalao:  python run.py
   (Ya isi folder me START-GENSPARK.bat double-click karo)

STEP 3: Browser me open karo
   - http://127.0.0.1:5000          → GenSpark home
   - http://127.0.0.1:5000/auth/login → Login
   - http://127.0.0.1:5000/admin/dashboard  → Admin Dashboard (Python Flask)
   - http://127.0.0.1:5000/vendor/dashboard → Vendor Dashboard (Python Flask)

Login: admin@genspark.com / admin123  (ya vendor@genspark.com / vendor123)
