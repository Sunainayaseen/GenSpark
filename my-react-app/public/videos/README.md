# Banner video – hero-bg.mp4

## 1. File yahan honi chahiye
- Is folder mein **hero-bg.mp4** rakhein: `my-react-app/public/videos/hero-bg.mp4`

## 2. App sahi jagah se chalaen
Terminal khol kar **my-react-app** folder ke andar jao, phir:
```
cd my-react-app
npm run dev
```

## 3. Video load check karein
Browser mein ye link open karein (app run karte waqt):
**http://localhost:5173/videos/hero-bg.mp4**

- Agar **video chal jati hai** → file sahi jagah hai; homepage par bhi chalni chahiye (Ctrl+Shift+R se refresh karein).
- Agar **404 ya error** aaye → file naam `hero-bg.mp4` hona chahiye aur path `my-react-app/public/videos/` hona chahiye.

## 4. Format
- **MP4 (H.264)** use karein taake sab browsers support karein.
